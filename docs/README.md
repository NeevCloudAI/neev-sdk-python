# Documentation

The full NeevCloud documentation lives at <https://docs.ai.neevcloud.com>. This directory
holds the guides and reference for `neevai`, the NeevCloud SDK for Python.

New here? Start with **[Getting started](./getting-started.md)**.

| Document | What you'll find |
| --- | --- |
| [Getting started](./getting-started.md) | Install, set your credentials, and run code in your first sandbox |
| [Sandboxes](./sandboxes.md) | Commands, files, code interpreter, terminals, preview URLs, egress, snapshots and more |
| [Agents](./agents.md) | Ready-made coding agents, such as Claude Code |
| [Agent tools](./agent-tools.md) | Sandbox tools for the agent you build, with framework adapters |
| [Configuration](./configuration.md) | Credentials, organization and project, client options, timeouts and the raw client |
| [Errors](./errors.md) | Error classes, error codes and what to retry |
| [API reference](./api-reference.md) | Every public method, grouped by product, with sync and async snippets |
| [API inventory](./api-inventory.md) | Full signatures, parameter tables, types and errors |
| [Use from an AI agent](./ai-agents.md) | Prompts to paste into a coding agent, and the rules it follows to use the SDK |

**Contributing:** [Development](./development.md) covers setup, tests and keeping these
docs current, and [Example coverage](./example-coverage.md) maps each API to the example
that shows it.

For runnable scripts, see [`examples/`](../examples/README.md).
